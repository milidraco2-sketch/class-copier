# 类名复制器 (Class Copier)

一个给 **SillyTavern** 用的第三方扩展，开启后单击页面任意元素即可复制它的 CSS 选择器（`#id.class1.class2`），方便写自定义 CSS、脚本或调试主题。

## 功能

- **单击复制**：单击页面任意元素，自动复制它的 `id` / `class`（CSS 选择器格式），并弹出提示。
- **双击放行**：双击则触发元素原本的点击逻辑。比如双击魔棒按钮会正常打开扩展菜单、双击视图外会跳回默认界面，不会因为开了复制器而失效。
- **悬停高亮**：鼠标划过元素时绿色描边，方便看清当前会复制哪一个。
- **两层开关**：
  - **总开关**（魔棒菜单里的「类名复制器：开 / 关」）：关闭时整个插件完全停用，悬浮按钮消失、不拦截任何事件，跟没装一样。
  - **复制模式**（悬浮按钮）：总开关打开后才有意义，控制是否拦截点击并复制。
- **悬浮按钮可拖动**：位置自动记忆，刷新后不会跑回去。
- **Esc 快速退出**：复制模式下按 `Esc` 直接关掉复制模式。
- **魔棒菜单同步**：总开关状态和菜单文字实时同步，换界面后菜单项会自动补回。

## 安装

在 SillyTavern 的 **扩展 (Extensions)** 面板中：

1. 点击 **Install extension**（安装扩展）。
2. 粘贴本仓库地址：

   ```
   https://github.com/milidraco2-sketch/class-copier
   ```

3. 点击安装，刷新页面。

## 使用

1. 打开魔棒菜单（右上角的图标）。
2. 找到 **「类名复制器：关」**，点一下变成 **「开」**（文字变绿）。
3. 此时右下角（或上次拖动后的位置）会出现悬浮按钮 **类名复制器**（按钮上带一个复制图标）。
4. 点一下悬浮按钮进入复制模式，按钮文字变为 **点击复制（开）**。
5. 单击页面任意元素，复制其选择器；双击则触发该元素原本的功能。
6. 不用时再点一下悬浮按钮退出复制模式，或到魔棒菜单里关掉总开关彻底停用。

## 使用小贴士

- 开着复制模式时，**菜单里的其它插件项也是"单击复制、双击触发"**。想点某个插件却忘了双击，再双击一下即可。
- 想复制魔棒按钮本身的选择器，直接单击魔棒按钮即可；想打开菜单就双击。
- 悬浮按钮的复制模式与总开关是独立的：关掉总开关会强制退出复制模式，下次开启总开关是干净的"复制模式关"状态。
